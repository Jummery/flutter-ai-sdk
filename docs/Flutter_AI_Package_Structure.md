# Flutter AI Package Structure

## Overview

Enterprise Flutter AI SDK package organization.

## Packages

- flutter_ai_core: domain models and interfaces
- flutter_ai_chat: conversation engine
- flutter_ai_model: model providers
- flutter_ai_network: transport layer
- flutter_ai_storage: persistence
- flutter_ai_ui: reusable components

## Design Goal

Modular, extensible, testable and provider independent.
