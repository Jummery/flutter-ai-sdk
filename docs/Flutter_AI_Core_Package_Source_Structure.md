# Flutter AI Core Package Source Structure

## Overview

Defines the foundational package of Flutter AI SDK.

## Package Layout

```
flutter_ai_core
lib/src
 ├── client
 ├── model
 ├── chat
 ├── message
 ├── stream
 ├── config
 └── exception
```

## Responsibilities

- Unified AI client
- Model abstraction
- Message protocol
- Stream processing
- Error handling
